
# MMT&GC - Construction & Transport Website

A PHP, MySQL, and Bootstrap 5 professional, responsive website built for **Middle Mountain Transport & General Contracting**. This platform showcases construction services, project portfolios, and team expertise with a focus on a responsive user experience.

🌟 **Key Features**
* **Dynamic Portfolio:** Categorized project gallery with detailed project views.

* **Service Management:** Dedicated pages for General Construction and Structural Repairs.

* **Admin-Ready Database:** Powered by a MySQL backend to manage reviews, team members, and project uploads.

* **Responsive Design:** Built with Bootstrap 5 and AOS (Animate On Scroll) for modern UI/UX.

## 🚀 Tech Stack
* **Frontend:** Bootstrap 5, AOS (Animate on Scroll), FontAwesome.
* **Backend:** PHP.
* **Database:** MySQL.

## 🛠️ Installation
1.  **Clone the repo:** `git clone <your-repo-link>`
2.  **Database Setup:** * Create a database named `mmt&gc` in your MySQL server.
    * Import the `mmt_gc.sql` file provided in the root directory.
3.  **Config:** Update `inc/db.php` with your local database credentials (host, username, password).
4.  **Run:** Move the files to your local server (XAMPP/WAMP) and access it via `localhost`.

## 📂 Project Structure
* `/inc`: Contains database connections, header, and footer.
